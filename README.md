Sistema que gera personagens únicos a cada execução, com atributos aleatórios: origem, nível, tipo de energia, técnica amaldiçoada, habilidades, expansão de domínio, estilo de luta, personalidade e fraquezas.
Conceitos aplicados: classes e objetos, construtores, arrays, a classe Random e organização do código.
Próximos passos: sistema de raridade no estilo gacha e interface gráfica.

Competências: Java · POO
